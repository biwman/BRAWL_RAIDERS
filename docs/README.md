# STARJACKERS Website

Statyczna strona promocyjna gry STARJACKERS przygotowana pod GitHub Pages.

Strona ma domyślną wersję angielską, przełącznik języka EN/PL, osadzony zwiastun z YouTube, galerię z 8 screenami z gry, przewijane poziomo sekcje statków i gadżetów oraz zakładkę Privacy Policy.

Publikacja:

1. Wejdź w repozytorium na GitHubie: `https://github.com/biwman/STARJACKERS`.
2. Otwórz `Settings -> Pages`.
3. Wybierz `Deploy from a branch`.
4. Branch: `main`, folder: `/docs`.
5. Zapisz ustawienia.

Po chwili GitHub Pages powinien wystawić stronę pod adresem:

`https://biwman.github.io/STARJACKERS/`

Najważniejsze pliki:

- `index.html` - treść strony.
- `styles.css` - wygląd i responsywność.
- `script.js` - menu mobilne, galeria i animacje wejścia.
- `assets/images/` - webowe kopie grafik z projektu Unity.
